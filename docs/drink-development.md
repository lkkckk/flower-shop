# 饮品规格开发与验收

用户已批准：自定义规格组合、独立售价及批量填价、不管理库存、不区分客户等级价格、手机选规格、订单快照、小票、退款和报表。只做本地开发，不提交、推送或部署。

## 工作记录

- 商品配置表单：完成规格组、排序、组合生成及批量价格；真实浏览器创建和编辑通过。
- 收银与购物车：完成规格选择、整杯数量、组合分行、持久化及结账前目录校验。
- 账务、退款和报表：完成服务端权威价格、无库存销售、无库存退款和未核算饮品收入展示。
- 隔离环境验收：真实 PostgreSQL 及 Chromium 验证通过，详见下方。

## 实现约定
- 普通商品默认 `standard`，饮品 `drink`；已有商品类型不转换。
- 规格、选项、组合使用稳定字符串标识；组合移除停用保留。
- 结账 `expectedUnitPrice` 是组合优惠前基础售价；服务器决定最终价格。
- 组合最多 200 种，防止错误配置产生无法操作的大表单；规格名和选项允许编辑，身份不随名称改变。
- 饮品不产生库存、批次成本；保留销售额但单列未核算饮品收入。

## 本地重跑

Windows 上旧服务会占用默认 `.output` 的 Prisma DLL，使用独立输出目录：

```powershell
$env:FLOWER_BUILD_OUTPUT = '.cache/drink-final-output'
pnpm build
node tests/drink-acceptance.mjs
node tests/cleanup-and-noshift-acceptance.mjs
```

浏览器验收可运行 `node tests/drink-acceptance.mjs --serve`，用交互终端运行，输入回车清理退出。地址和测试账号写在 `.cache/drink-browser.json`。截图及PDF位于 `output/playwright/drink-*`，不纳入提交。

初次开发验收仅在隔离数据库执行迁移。2026-09-19 根据本地启动缺少 `Product.productType` 的报错，已将 `20260919000100_drink_variants` 应用到本机 `localhost:55432/flower_shop` 的 public schema；VPS仍未操作。没有提交、推送或发布。
